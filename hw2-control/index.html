    控制原理

    PQ 控制采用功率外环 + 电流内环双闭环结构：功率指令与实测功率比较后经 PI 调节生成电流指令，再经电流内环与 PWM 调制驱动逆变桥。适用于并网运行、按调度指令输出功率的场景。

    仿真操作

    ① 上方切换 控制结构 与 控制策略；② 拖动右侧滑块修改 功率指令 / 下垂系数 / 负荷；③ 点击 投入负荷 观察频率与功率重新分配；④ 点击 三相短路故障 观察电压跌落与恢复过程；⑤ 观察三条曲线与事件记录。

    观察要点

    PQ 模式下频率与电压由大电网支撑，负荷变化不影响逆变器输出功率；切换到 下垂控制 后，负荷增加将引起频率下降，且下垂系数越大频率偏差越大，体现“有功—频率”的下垂特性。
